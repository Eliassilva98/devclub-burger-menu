🍔 Projeto DevClub Burger

Mais um projeto concluído no módulo de JavaScript, mas dessa vez diferente de todos os anteriores.

O professor Rodolfo Mori sempre nos incentiva a diferenciar nossos projetos — seja mudando a cor de um botão, ajustando o background ou adicionando um detalhe extra para que nenhum projeto fique igual ao outro. E foi exatamente isso que fiz aqui.

Neste projeto, eu criei um background em linear-gradient na cor mostarda, troquei as cores dos botões e adicionei um efeito hover com:

transform: scale(1.05);


Esse efeito permite que os botões aumentem levemente ao passar o mouse por cima, sem alterar o layout da página, deixando a interface mais dinâmica e moderna.

🧠 Lógica da Aplicação

A aplicação funciona da seguinte forma:

Mostrar tudo (forEach) → Exibe todos os itens do cardápio.

Mapear (map) → Aplica 10% de desconto em cada lanche.

Somar tudo (reduce) → Calcula o valor total dos produtos já com os 10% de desconto aplicados.

Filtrar (filter) → Mostra apenas os lanches veganos.

Também utilizamos uma função específica para fazer a formatação dos valores em reais (R$), garantindo que os preços sejam exibidos corretamente.
